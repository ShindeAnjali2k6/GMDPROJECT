# 🏜️ Desert Escape Maze

**A 3D Maze Exploration and Escape Game | Unity 6**

## 📌 Project Overview

Desert Escape Maze is a 3D maze-based adventure game developed using Unity. Set in a desert-themed environment, the game challenges players to navigate through a maze, explore different paths, avoid getting lost, and find the exit to escape.

The game uses a **third-person camera perspective**, allowing players to control and observe their character while exploring the maze.

The project focuses on simple gameplay, 3D environment design, player movement, camera navigation, and maze exploration.

## 🎯 Project Objectives

- Develop an interactive 3D maze environment.
- Implement third-person player movement and camera control.
- Create an engaging desert-themed gaming environment.
- Provide a simple maze navigation and escape objective.
- Understand fundamental Unity game development concepts.

## ✨ Key Features

- **Desert Environment:** A maze designed around a desert-inspired theme.
- **Third-Person Perspective:** Explore the environment using a third-person camera.
- **Maze Navigation:** Navigate through paths and find the correct route.
- **Escape Objective:** Reach the maze exit to complete the game.
- **3D Gameplay:** Interactive gameplay within a three-dimensional environment.
- **Simple Game Mechanics:** Easy-to-understand gameplay suitable for beginners.

## ⚙️ Installation and Setup

Follow these steps to download and run the project locally.

**Step 1: Clone the Repository**

Open a terminal and execute:

```bash
git clone https://github.com/ShindeAnjali2k6/GMDPROJECT.git
```

**Step 2: Open the Project**

1. Open Unity Hub.
2. Select **Add → Add project from disk**.
3. Browse to the cloned `GMDPROJECT` folder.
4. Select the project.

**Step 3: Select Unity Version**

Open the project using:

```text
Unity 6000.6.0f1
```

**Step 4: Run the Game**

1. Wait for Unity to import the project assets and resolve packages.
2. Open the main game scene from the Assets folder.
3. Press the **Play** button in Unity Editor.
4. Start exploring the maze.
